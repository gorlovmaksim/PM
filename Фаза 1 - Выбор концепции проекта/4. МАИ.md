# Чёткий коллективный МАИ

## Методика

Иерархия: цель → четыре критерия → четыре альтернативы. Для каждого эксперта матрицы попарных сравнений построены как отношения его положительных балльных оценок (aᵢⱼ = vᵢ/vⱼ). Такие матрицы идеально согласованы (CR = 0), но это **упрощённая учебная модель**, а не независимо заполненные матрицы по шкале Саати. Для строгого выполнения задания участникам следует отдельно провести попарные сравнения и проверить CR.

Индивидуальные приоритеты получены нормированием исходных векторов. Коллективные приоритеты — нормированное геометрическое среднее индивидуальных векторов.
