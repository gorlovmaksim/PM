# Нечёткий коллективный TOPSIS

## Метод

Все критерии — выгодные. Для каждой альтернативы и критерия берём треугольное число (минимум, медиана, максимум) по четырём участникам. Нормализация: деление на 10. Веса критериев агрегируются аналогично, затем делятся на сумму средних весов. Взвешенная матрица получается покомпонентным умножением. Положительный и отрицательный идеалы — покомпонентные максимумы и минимумы. Расстояние вычисляется евклидовой метрикой с делением суммы квадратов на 3. Коэффициент близости: D−/(D+ + D−).
