## Структура

- **Таск трекер** — RACI и учёт трудозатрат.
- **Фаза 1 - Выбор концепции проекта** — оценки, вычисления, отчёт, выводы.
- **Фазы 2–5** — пустые заготовки на следующие этапы.

## Статус

- **Фаза 1:** документы, расчёты TOPSIS и МАИ, сравнение и выводы подготовлены. Экспертные оценки требуют проверки и подтверждения участниками.
