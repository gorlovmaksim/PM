## Структура

- **Таск трекер** — RACI и учёт трудозатрат.
- **Фаза 1 - Выбор концепции проекта** — оценки, вычисления, отчёт, выводы.
- **Фаза 2** — распределение работ фазы 3 на основе целочисленной оптимизации.
- **Фаза 3** — 12 Use Cases, COSMIC FP, UCP и оценки трудозатрат.
- **Фазы 4–5** — заготовки на следующие этапы.
